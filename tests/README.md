# Tests

Build the application, then run the complete test runner from the repository root:

```sh
python3 build.py
npm test
```

- `*.test.mjs`: Node test suites for model and application behavior.
- `regression/`: standalone regression scripts retained from the earlier root layout.
- `results/`: JSON reports generated by those scripts.

The runner uses the repository root as its working directory. Figure-test exports go to ignored `test-output/figures/`.

Literature inputs used by the application belong to [research/literature/](../research/literature/README.md), separate from generated test reports. See the [verification guide](../docs/verification.md) for the distinction between numerical tests and physical validation.
